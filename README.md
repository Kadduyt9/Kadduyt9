### 👨‍💻 About Me

I am a software engineer focused on building robust backend systems, automated event-driven bots, AI agent workflows, and network protocol utilities. 

- ⚡ **Backend & APIs:** Designing high-concurrency RESTful services, secure request pipelines, and webhook handlers.
- 🤖 **Bots & Automation:** Developing scalable Telegram automation engines, asynchronous event loops (`aiohttp`), and workflow scripts.
- 🧠 **AI & Tooling:** Integrating intelligent agent capabilities, LLM tooling, and automated scraping/research utilities.
